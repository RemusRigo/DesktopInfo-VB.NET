# DesktopInfo
DesktopInfo: shows Windows and network information on your desktop



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Shows on the desktop: user & computer name, OS, version, build number, feature update & codename, private and public IP
* Acrylic blur effect
* Window hidden from the TaskBar and Alt-TAB
* Position: any corner of the primary monitor
* Tray icon menu: About, Options, Exit
* Start with Windows for the current user or all users
* Save settings to JSON file
* Tested on:
  * Windows 11 Pro | Enterprise LTSC
